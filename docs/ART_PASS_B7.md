# P7 — три пробы проекции

База: `fb453f5` (`main`). Ветка: `cod/visual-b7-hex-footprint`.
Это первая часть P7 для утверждения проекции, не завершение всех 43 ассетов.

## Что подключено

В `godot/assets/buildings/tiers/` добавлены PNG RGBA 1024×1024:

- `shelter_t1_hex.png` — барак с прямым фасадом;
- `well_pump_t1_hex.png` — колодец с горизонтальным воротом и корытом;
- `source_tower_old_t1_hex.png` — старая башня с фронтальной рамой.

У трёх определений в `buildings.json` добавлен `footprint: hex`, заменён только t1.
Рендер использует ширину `HEX_SIZE × 2 × 1.04`, якорь `draw_size.y − width × 0.325`
и не рисует дополнительную тёмную подложку. Поскольку это частичная миграция,
гекс-ветка требует одновременно флаг и суффикс выбранного спрайта `_hex.png`:
t2/t3 барака и насоса сохраняют ромбовый якорь и подложку. Обрезка силуэта,
повреждения, уровни, сортировка и цветной fallback сохранены.

## Генерация

Использован встроенный `image_gen`; все промпты, исходные пути и выбранные
попытки записаны в [ART_PASS_B7_PROMPTS.json](ART_PASS_B7_PROMPTS.json).
Референсы материалов: прежние барак, колодец и башня; референс земли —
`tile_dust.png`. Для правок использован [точный шаблон гекса](art/p7_hex_layout.png).

Всего семь генераций/правок: три исходных и по две правки насоса и башни.
Первый промпт исправил ориентацию фасадов, но у насоса и башни сделал слишком
плоскую юбку. Правка с требованием увеличить глубину земли помогла башне;
последняя попытка насоса, наоборот, сделала юбку слишком глубокой, поэтому
выбрана предыдущая. Для барака оставлена первая попытка.

Подготовка PNG: обрезка внешнего прозрачного поля по alpha > 0.05, равномерное
масштабирование до ширины 800 px (высота не более 940 px), размещение по центру
холста 1024×1024 с нижним краем на y=964. Alpha сохранён; ручной дорисовки,
растяжения отдельных частей и подмены иллюстраций вектором нет.

## Визуальная проверка

- [Карта до](images/visual_pass_b_p7_before.png) / [после](images/visual_pass_b_p7.png), seed=12345.
- [Кропы карты 3×](images/visual_pass_b_p7_crops.png): все три заменённых здания.
- [Рендер до](images/visual_pass_b_p7_trials_before.png) / [после](images/visual_pass_b_p7_trials.png):
  масштаб 4×, игровой 1×, соседние клетки 2×; золотой контур показывает настоящую границу клетки.
- [Контактный лист](images/visual_pass_b_p7_sheet.png): каждый спрайт рядом с тайлом той же ширины, включая 64 px.

Прямые фасады и разные силуэты читаются. Основания теперь шестигранные.
Край нарисованной юбки не является точной математической маской: около боковых
вершин насоса и башни остаётся небольшое расхождение с контуром клетки,
усиленное заданным запасом ширины 1.04. Это видно на увеличенном сравнении;
пиксельное совпадение всех шести рёбер и окончательная визуальная приёмка пока
не заявляются. На утверждение вынесены ракурс, масштаб и посадка этих трёх проб.

```sh

Godot --headless --path godot --quit-after 240
Godot --headless --path godot res://tools/balance_sim.tscn
Godot --headless --path godot res://tools/save_roundtrip.tscn
Godot --path godot --resolution 1280x720 res://tools/screenshot.tscn -- out=/abs/existing/dir seed=12345
Godot --path godot --resolution 1280x900 res://tools/hex_footprint_preview.tscn -- out=/abs/existing/dir
Godot --path godot --resolution 1280x900 res://tools/hex_footprint_preview.tscn -- out=/abs/existing/dir legacy
```

Импорт и boot без SCRIPT ERROR / Parse Error / Failed to load.
Полные логи `balance_sim` до/после совпадают байт-в-байт, включая A–F:
[до](validation/p7/balance-before.log), [после](validation/p7/balance-after.log).
[Сохранение](validation/p7/save-roundtrip.log): `ROUND-TRIP: 0 differing fields`.
Сцена сравнения также проверяет выбор гекс-ветки для t1, ромбовой ветки для
t2/t3, отсутствие флага и отсутствующий спрайт. PNG проверены на размер,
настоящую прозрачность и отсутствие касания краёв холста. `git diff --check` чистый.
